# The Atelier — Tailoring Order Workshop

The browser interface for the Tailoring Workshop project lives here. Open `index.html` directly, or use the repository root `index.html` / `Open_Workshop_Interface.bat` to launch it.

This is a standalone browser demo with in-memory data. It does not read or write the C++ console application's data. Tailwind CSS and the fonts load from CDNs, so an internet connection is needed for the complete styling.
